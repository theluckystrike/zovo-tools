How Binary Encoding Works

The Binary Number System

Binary is a base-2 number system. Unlike decimal (base-10), which uses ten digits (0–9), binary uses only two: 0 and 1. Each position in a binary number represents a power of 2, starting from the right.

For example, the binary number 1101 equals:

  • 1 × 2³ = 8
  • 1 × 2² = 4
  • 0 × 2¹ = 0
  • 1 × 2⁰ = 1
  • Total: 13 in decimal

Text to Binary: Character Encoding

Computers store text by assigning each character a numeric code point. The most common encoding standard is UTF-8, which is backward-compatible with ASCII. In ASCII, the capital letter "A" has code point 65, which is 01000001 in 8-bit binary.

UTF-8 uses a variable-length encoding scheme:

  • 1 byte (8 bits): Standard ASCII characters (U+0000 to U+007F)
  • 2 bytes (16 bits): Latin extensions, Greek, Cyrillic (U+0080 to U+07FF)
  • 3 bytes (24 bits): Chinese, Japanese, Korean, most symbols (U+0800 to U+FFFF)
  • 4 bytes (32 bits): Emoji, rare scripts, mathematical symbols (U+10000 to U+10FFFF)

This means a simple English sentence might use exactly one byte per character, while a Chinese character uses three bytes. The binary translator on this page uses proper UTF-8 encoding, so every character — from "A" to emoji — converts correctly.

Why Binary Matters

Binary is not just an academic concept — it is the fundamental language of every digital device. Processors execute binary machine code, RAM stores data in binary cells, hard drives encode binary values magnetically, and fiber-optic cables transmit binary as light pulses. Understanding binary helps developers debug encoding issues, work with bitwise operations, and build efficient data structures.

For more on binary and computer science fundamentals, see the Wikipedia article on binary numbers and MDN's UTF-8 documentation.

Frequently Asked Questions

What is binary code?
Binary code is a number system that uses only two digits: 0 and 1. Computers process all data as binary because digital circuits have two states — on (1) and off (0). Each binary digit is called a bit, and groups of 8 bits form a byte, which can represent values from 0 to 255.
How do you convert text to binary?
Each character in text has a numeric code point. In ASCII, the letter 'A' is 65, which in binary is 01000001. For UTF-8 encoding, characters use 1 to 4 bytes depending on the code point. A binary translator maps each character to its code point, then converts that number to base-2 representation.
What is the difference between 7-bit and 8-bit binary?
7-bit binary can represent values from 0 to 127, which covers the standard ASCII character set (English letters, digits, and common symbols). 8-bit binary extends this to 0–255, which is needed for extended ASCII characters and is the standard byte size used in UTF-8 encoding.
Can binary represent languages other than English?
Yes. UTF-8 encoding supports all Unicode characters, including Chinese, Arabic, Japanese, emoji, and every other writing system. Characters outside the basic ASCII range use 2 to 4 bytes in UTF-8. This translator fully supports UTF-8 multi-byte encoding.
What is Morse code and how does it relate to binary?
Morse code represents letters using dots and dashes — conceptually similar to binary's 0s and 1s. While Morse code is not a binary encoding in the strict sense, both systems encode information using two distinct symbols. Morse was one of the earliest digital communication methods.
How do computers use binary?
Computers use binary at every level. Processors execute binary instructions, memory stores binary data, and all files are sequences of binary bytes. Text, images, audio, and video are all represented as binary data with different encoding schemes interpreting the bits.
