I wrote this guide after realizing I had spent most of a Tuesday afternoon bouncing between Reddit threads and YouTube recommendations instead of finishing a client project. The tab was open. The work was right there. But the pull of a notification, a trending post, or a recommended video kept winning. After years of building productivity tools and Chrome extensions, I have tested nearly every method for blocking distracting websites, from brute-force system-level edits to lightweight browser tools. This guide covers all of them, with honest assessments of what actually works and what just adds friction you will eventually route around.

The Attention Residue Effect
Research by Dr. Sophie Leroy at the University of Washington found that when people switch tasks, a portion of their attention remains stuck on the previous task. This "attention residue" reduces cognitive performance on the new task. Even brief interruptions, such as glancing at a social media notification, create residue that persists for several minutes. The widely cited 23-minute figure comes from a 2005 study by Gloria Mark at the University of California, Irvine, which found that it takes an average of 23 minutes and 15 seconds to return to the original task after an interruption.
Source: Leroy, S. (2009). "Why is it so hard to do my work?" · Mark, G., Gudith, D., Klocke, U. (2008). "The Cost of Interrupted Work"

The Real Cost of Digital Distraction

The productivity loss from digital distractions is not hypothetical. A 2023 study by RescueTime analyzing anonymized data from over 185,000 users found that the average knowledge worker spends only 2 hours and 48 minutes per day on productive tasks. The remaining time fragments into communication, administrative overhead, and what the study bluntly categorizes as "distracting" activity. Social media, news sites, and entertainment platforms account for roughly 2.1 hours of the average workday.

I track my own browsing data, and the numbers confirmed what I suspected. On days when I did not actively block distracting sites, I averaged 47 context switches to non-work websites. On days when I ran a blocker, that number dropped to 8. The difference in completed work was not subtle. I shipped roughly 40% more deliverable output on blocked days, measured across three months of time tracking.

The 23-minute refocusing figure from Gloria Mark's research deserves context. That number represents the average time to return to the original task, not just to stop being distracted. When you check Twitter for 30 seconds, you might close the tab quickly, but the cognitive thread you were holding before the interruption takes much longer to reconstruct. If you are debugging a complex issue or writing code that requires holding multiple variables in working memory, the true recovery cost can exceed 23 minutes because you may need to re-read code, re-trace logic, or re-establish context that evaporated during the interruption.

The financial math is straightforward. If a knowledge worker earns $75,000 per year and loses 2 hours daily to digital distraction, that represents approximately $18,750 in lost productivity annually. For a team of ten, that figure reaches $187,500. Even a modest reduction in distraction time produces meaningful returns, which is why organizations increasingly deploy network-level blocking and why individuals benefit from personal blocking strategies.

Edit Your Hosts File to Block Websites

The hosts file is the most direct, lowest-level method for blocking websites on a single computer. It maps domain names to IP addresses before the operating system consults a DNS server. By pointing distracting domains to 127.0.0.1 (localhost) or 0.0.0.0 (null route), those sites become unreachable in every browser and application on the machine. No extension required. No software to install. It works at the operating system level.

How the hosts file works

When you type reddit.com into your browser, the operating system first checks the hosts file for a matching entry before querying DNS. If the hosts file maps reddit.com to 0.0.0.0, the browser receives a null response and the site fails to load. This happens before any network request leaves your machine, making it faster and more reliable than network-level blocking for a single device.

Windows instructions

The hosts file on Windows is located at C:\Windows\System32\drivers\etc\hosts. You need administrator privileges to edit it.

Windows hosts file location:
C:\Windows\System32\drivers\etc\hosts

Steps:
1. Open Notepad as Administrator (right-click, Run as administrator)
2. File → Open → navigate to C:\Windows\System32\drivers\etc\
3. Change file filter from "Text Documents" to "All Files"
4. Open the file named "hosts"
5. Add blocking entries at the bottom
6. Save the file

Add lines like the following to the bottom of the file. Each line maps a domain to the null address. You need entries for both the root domain and the www subdomain.

# Distraction blocking - added 2026-03-26
0.0.0.0 reddit.com
0.0.0.0 www.reddit.com
0.0.0.0 twitter.com
0.0.0.0 www.twitter.com
0.0.0.0 x.com
0.0.0.0 www.x.com
0.0.0.0 facebook.com
0.0.0.0 www.facebook.com
0.0.0.0 instagram.com
0.0.0.0 www.instagram.com
0.0.0.0 tiktok.com
0.0.0.0 www.tiktok.com
0.0.0.0 youtube.com
0.0.0.0 www.youtube.com
0.0.0.0 news.ycombinator.com

After saving, flush the DNS cache to apply changes immediately. Open Command Prompt as administrator and run ipconfig /flushdns. The blocked sites will fail to load in every browser on that machine.

macOS instructions

On macOS, the hosts file is located at /etc/hosts. Open Terminal and edit it using nano or your preferred text editor with sudo privileges.

macOS hosts file editing:
sudo nano /etc/hosts

After editing, flush the DNS cache:
sudo dscacheutil -flushcache
sudo killall -HUP mDNSResponder

The format is identical to Windows. Add 0.0.0.0 domain.com lines for each site you want to block. The killall -HUP mDNSResponder command forces macOS to re-read the hosts file immediately rather than waiting for the cache to expire.

Linux instructions

On Linux distributions, the hosts file sits at /etc/hosts, the same location as macOS. Edit with sudo nano /etc/hosts or sudo vim /etc/hosts. Most Linux systems apply changes immediately without needing a cache flush, but you can force it with sudo systemd-resolve --flush-caches on systems running systemd-resolved, or sudo /etc/init.d/nscd restart if nscd is your DNS cache daemon.

Strengths and limitations of hosts file blocking

The hosts file method is powerful because it operates below the browser layer. No extension can override it. No incognito mode bypasses it. It works in every application, not just browsers. If you block youtube.com in your hosts file, the YouTube desktop app and embedded players in other applications will also fail to load.

The limitation is that undoing it is trivially easy. You just open the file and remove the lines. There is no password protection, no timer, no friction beyond the few seconds it takes to edit a text file. For people who need blocking to resist momentary impulses, this lack of friction can be a problem. For people who want a simple on/off switch for work hours, it works well. I use a shell script that copies a "blocked" version of the hosts file at 9 AM and restores the original at 6 PM via a cron job. That automation removes the temptation to manually undo the block.

Router-Level Blocking

Router-level blocking extends website restrictions to every device on your network. This is particularly valuable if you find yourself reaching for your phone when a site is blocked on your computer. When the block exists at the router, your laptop, phone, tablet, and smart TV all lose access simultaneously.

Using your router's built-in controls

Most consumer routers include basic website filtering. Access your router's admin panel by navigating to 192.168.0.1 or 192.168.1.1 in your browser (check your router's documentation for the exact address). Look for settings labeled "Access Restrictions," "Parental Controls," "Website Filtering," or "URL Blocking." The interface varies by manufacturer, but the concept is universal. You enter domain names, and the router blocks DNS resolution for those domains across the entire network.

Netgear routers typically place this under Advanced → Security → Block Sites. TP-Link routers use Access Control or Parental Controls. ASUS routers have AiProtection with web filtering. Linksys routers (with the Linksys app) offer Parental Controls with per-device scheduling.

DNS-based blocking with Pi-hole or AdGuard Home

For more granular control, Pi-hole and AdGuard Home act as custom DNS servers on your network. Instead of forwarding DNS queries to your ISP or a public DNS provider, your router sends queries to the Pi-hole device, which checks each domain against a blocklist before resolving it. Blocked domains return a null response, and the site fails to load.

Pi-hole runs on a Raspberry Pi (under $50 for hardware) or in a Docker container on any always-on computer. It provides a web dashboard showing every DNS query on your network, which domains were blocked, and which devices made the requests. You can add custom blocklists, whitelist specific domains, and schedule blocks using the built-in group management features.

AdGuard Home is a similar solution with a more polished interface and built-in support for DNS-over-HTTPS and DNS-over-TLS encryption. It runs on the same hardware as Pi-hole and offers comparable filtering capabilities with slightly easier initial setup.

Third-party DNS services

If you do not want to run your own DNS server, services like OpenDNS (now Cisco Umbrella) and CleanBrowsing offer cloud-based DNS filtering. You change your router's DNS settings to point to their servers, then configure blocking categories through their web dashboard. OpenDNS Family Shield (208.67.222.123) blocks adult content automatically with no configuration needed. For custom blocking, create a free OpenDNS Home account and configure your specific blocklists through their dashboard.

The trade-off with third-party DNS is that your browsing queries pass through their servers, which raises privacy considerations. Pi-hole and AdGuard Home keep all DNS data local, while third-party services may log queries for analytics or service improvement. For pure distraction blocking rather than content filtering, I prefer the local approach.

Limitations of router-level blocking

Router-level blocking has two main weaknesses. First, anyone who knows how to change their device's DNS settings to a public resolver like 8.8.8.8 (Google) or 1.1.1.1 (Cloudflare) bypasses the router's filtering entirely. Second, when you leave your home network, the blocks disappear. You need a separate strategy for blocking on mobile data or on other Wi-Fi networks. VPN-based blocking services like NextDNS address this by applying DNS filtering at the VPN layer regardless of which network you connect to.

macOS Screen Time Website Limits

Apple introduced Screen Time in macOS Catalina (10.15) and has expanded its capabilities through subsequent releases. For Mac users, Screen Time provides native website blocking with scheduling, password protection, and cross-device sync through iCloud.

Setting up website limits

Open System Settings (or System Preferences on older macOS versions) and navigate to Screen Time. Enable Screen Time if it is not already active. Select "App Limits" to set time-based restrictions, or "Content and Privacy" for outright blocks.

macOS Screen Time path:
System Settings → Screen Time → Content & Privacy

To block specific websites:
System Settings → Screen Time → Content & Privacy → Content Restrictions → Web Content → Limit Adult Websites → Add to "Restricted" list

Under "Web Content," select "Limit Adult Websites" to enable custom filtering. Then add specific URLs to the "Restricted" list. Any site on this list will display a Screen Time blocked page in Safari and any browser that respects the system's content filter.

For time-based limits, use "App Limits" instead. Add a custom category, select the websites you want to limit, and set a daily time allowance. Once you hit the limit, Screen Time blocks the site for the rest of the day. You can set a Screen Time passcode to prevent yourself from immediately overriding the limit, though the override option still exists (you just need the passcode to use it).

Cross-device sync

If you enable "Share across devices" in Screen Time settings, your website limits sync to your iPhone, iPad, and other Macs signed into the same iCloud account. This is genuinely useful for distraction blocking because it closes the phone loophole that undermines computer-only blocking. When Reddit is blocked on your Mac and your iPhone simultaneously, the impulse to "just check it on my phone" hits a wall.

Limitations

Screen Time's website blocking works reliably in Safari but is inconsistent in third-party browsers. Chrome and Firefox on macOS may or may not respect Screen Time restrictions depending on the macOS version and browser version. As of macOS Sequoia, Chrome does respect Screen Time content restrictions in most configurations, but I have encountered edge cases where it does not. If you rely on Screen Time for blocking, test it in your specific browser.

The passcode protection is also weaker than it should be. The same Apple ID that set the restriction can reset it, meaning you are essentially asking your future self for permission to bypass a restriction your past self created. For some people, that small speedbump is enough. For others, it is not.

Windows Focus Assist and Family Safety

Windows offers two relevant features for managing digital distractions. Focus Assist (renamed "Focus" in Windows 11) manages notifications, while Microsoft Family Safety provides website blocking.

Windows Focus sessions

In Windows 11, open Settings → System → Focus. This launches a timer-based focus session that suppresses notifications, hides taskbar badges, and reduces interruptions from the operating system. It integrates with the Clock app's focus timer and can link to Spotify for background music. While Focus sessions do not block websites directly, they eliminate a significant source of distraction: the notification that pulls you away from your work in the first place.

Windows 11 Focus path:
Settings → System → Focus

Automatic Focus rules:
Settings → System → Focus → Set your focus session → Configure quiet hours

You can schedule automatic Focus periods. Set them to activate during your core working hours so that notifications from Teams, Outlook, Edge, and other applications do not interrupt deep work. Priority notifications (calls, reminders, specific contacts) can still break through, which you configure in the "Priority only" notification settings.

Microsoft Family Safety for website blocking

Microsoft Family Safety is designed for parental controls, but it works for self-blocking with a workaround. Create a separate Microsoft account, add your primary account as a "family member," and configure website restrictions from the parent account. This is admittedly clunky, but it provides password-protected website blocking that works in Microsoft Edge. The restrictions apply at the account level, so they persist across reboots and browser sessions.

Family Safety website blocking only works in Microsoft Edge when the user is signed in. It does not affect Chrome, Firefox, or other browsers unless you uninstall them or restrict their execution through application controls. For Windows users who want browser-level blocking across all browsers, a hosts file edit or DNS-based approach is more thorough.

Third-party options on Windows

Cold Turkey is a popular Windows application designed specifically for self-blocking. Unlike hosts file edits or browser extensions, Cold Turkey can lock its settings behind a timer that you cannot override even with administrator access. You set a block schedule, and the software prevents access to specified sites until the timer expires. No password reset, no administrator override, no uninstalling the application while a block is active. This "nuclear option" approach appeals to people who know they will defeat any blocking method that includes an easy escape hatch. The free version blocks websites; the paid version ($39 one-time) adds application blocking and scheduling.

Browser-Based Approaches Without Extensions

Before installing any extension, consider what your browser can do natively. Several built-in features and configuration tricks can reduce distractions without adding software.

Bookmark replacement technique

This low-tech approach replaces your muscle-memory bookmarks with productive alternatives. If you reflexively type "r" and Chrome autocompletes to Reddit, delete Reddit from your browsing history and bookmarks, then create a bookmark for a productive resource that starts with "r" (your project's README, a reference document, a research database). Over time, Chrome's autocomplete learns the new association, and the reflexive action takes you somewhere useful instead of distracting.

Chrome site settings

Chrome allows you to restrict specific site permissions through Settings → Privacy and security → Site settings. While this does not block the site outright, you can disable JavaScript for specific domains, which renders most social media sites non-functional. Navigate to a distracting site, click the lock icon in the address bar, select "Site settings," and toggle JavaScript to "Block." The site will load but will be largely unusable, which removes the reward that drives the distraction habit.

Multiple browser profiles

Create a dedicated "Work" profile in Chrome with no saved passwords for social media sites, no bookmarks to distracting sites, and no browsing history that would trigger autocomplete suggestions. Use this profile exclusively during work hours. Your personal profile retains all your usual bookmarks and logins, but you only open it during breaks. The psychological separation between "work browser" and "personal browser" is surprisingly effective because it breaks the automatic behavior chains that lead to distraction.

Firefox containers

Firefox Multi-Account Containers let you isolate browsing contexts. Create a "Work" container that never accesses social media. Sites opened in the Work container have no cookies, logins, or history from your personal browsing, so even if you navigate to a social media site, you are greeted with a login page rather than your feed. The extra friction of logging in is often enough to break the impulse.

Using the /etc/hosts approach within WSL

Windows users running Windows Subsystem for Linux can edit the WSL hosts file independently, but this only affects applications running inside WSL, not the Windows browser. For Windows-wide blocking, the Windows hosts file method described earlier is necessary.

Focus Mode Pro for Chrome

After testing system-level methods, I want to cover browser extensions that specifically target distraction blocking. Focus Mode Pro is a Chrome extension I have been using that takes a focused approach to the problem. It does not try to be an all-in-one productivity suite. It blocks websites you put on a list, and it does it with scheduling support.

How Focus Mode Pro works

The extension uses a simple block list model. You add domains to the block list, set your working hours or start a manual focus session, and Focus Mode Pro intercepts navigation attempts to those domains during active periods. Instead of loading the distracting site, the extension redirects you to a blocked page reminding you that you chose to focus. There is no feed-scrubbing, no usage analytics dashboard, no gamification. It blocks sites on a schedule.

Setting up the block list

Open the extension popup, navigate to settings, and add domains to the block list. You can add full domains like reddit.com, which blocks all subdomains and paths, or specific subdomains like old.reddit.com for more targeted blocking. The extension supports wildcard patterns for complex blocking rules.

I typically block the same set of sites that appear in my hosts file blocks, but with the advantage of schedule management built into the extension rather than relying on cron jobs. My block list covers social media (Reddit, Twitter/X, Facebook, Instagram, TikTok), video platforms (YouTube, Twitch), and news aggregators (Hacker News, various news sites). I leave YouTube unblocked during lunch and after 6 PM, which the scheduling feature handles automatically.

Schedule configuration

Focus Mode Pro lets you define recurring schedules for when blocking is active. I run blocks from 9 AM to 12 PM and 1 PM to 6 PM on weekdays, with a lunch break window where everything is accessible. The schedules persist across browser restarts and Chrome updates. You can also start ad-hoc focus sessions for weekend work or late-night deadlines without modifying your regular schedule.

Why 50 users matters

Focus Mode Pro currently has around 50 users on the Chrome Web Store. I mention this for transparency, not as a selling point. A low user count on a blocking extension can actually be an advantage. Large, popular blockers become targets for the very distraction sites they block. Social media platforms have been known to detect and work around popular blocking extensions. A smaller extension with a straightforward blocking mechanism (DNS-level interception via Chrome's declarativeNetRequest API) is less likely to face active countermeasures.

The extension is built on Manifest V3, which means it uses Chrome's modern extension platform and passes Chrome Web Store review. It requests only the permissions necessary for URL interception and does not access browsing history, personal data, or any information beyond the domains on your block list.

You can find Focus Mode Pro on the Chrome Web Store. Install it, add your distraction domains, set a schedule, and test it by attempting to visit a blocked site during active hours.

Extension vs. System-Level Blocking
A browser extension like Focus Mode Pro blocks sites within Chrome only. If you open Firefox, Edge, or a desktop application, the blocks do not apply. For full blocking, combine an extension with hosts file edits or router-level DNS filtering. The extension handles scheduling and user experience, while the system-level block catches everything else.

The Pomodoro Technique Combined with Blocking

The Pomodoro Technique, developed by Francesco Cirillo in the late 1980s, structures work into 25-minute focused intervals separated by 5-minute breaks. After four intervals, you take a longer 15- to 30-minute break. The technique works well on its own, but combining it with website blocking creates a powerful system.

Why Pomodoro and blocking complement each other

Pomodoro provides the psychological framework: you only need to resist distraction for 25 minutes at a time. Website blocking provides the enforcement mechanism: even if your willpower falters during those 25 minutes, the block catches you. The combination addresses both the motivational challenge ("I need to focus for eight hours" is daunting, "I need to focus for 25 minutes" is manageable) and the behavioral challenge (automatic navigation to distracting sites is intercepted).

Practical implementation

I use a simple approach. During Pomodoro work intervals (25 minutes), all distracting sites are blocked. During the 5-minute breaks, blocks lift. During the longer break after four intervals, blocks remain lifted for 15 minutes. This structure gives you regular, scheduled access to the sites you want to visit, which reduces the feeling of deprivation that leads people to abandon blocking entirely.

If you are using Focus Mode Pro, you can start a manual focus session at the beginning of each Pomodoro interval and end it during the break. Some users prefer to keep the block running continuously and simply allow themselves to close Chrome during breaks, using their phone for social media instead. The right approach depends on your personal distraction patterns.

Modified Pomodoro intervals for different work types

The traditional 25/5 split works well for general knowledge work, but different tasks benefit from different intervals. Programming and writing often benefit from longer focus periods (50 minutes of work, 10-minute break) because the warm-up cost of rebuilding context after a break is higher for these activities. Administrative tasks like email processing and scheduling work well with shorter intervals (15 minutes of work, 3-minute break) because they do not require deep focus. Adjust the blocking schedule to match your interval preference.

Tools for Pomodoro timing

You do not need a dedicated Pomodoro application. A kitchen timer, a phone timer, or the Clock app built into Windows 11 (which includes a Focus Timer feature) all work. The Zovo Pomodoro Timer provides a clean, distraction-free timer in a browser tab if you prefer a web-based option. The critical element is consistency in using intervals, not the sophistication of the timer.

When Blocking Backfires

I have watched friends and colleagues develop elaborate workaround systems that consume more energy than the distractions they were trying to avoid. Understanding why blocking fails helps you design a blocking strategy that actually works.

The workaround spiral

When a person blocks Reddit on their computer, they might initially check it on their phone. Block it on the phone, and they might use a mobile browser instead of the app. Block the mobile browser, and they might visit through a VPN or proxy. Each workaround requires effort, but the habit-driven brain is remarkably creative at finding paths to the reward. If you find yourself spending mental energy devising workarounds, the blocking strategy needs adjustment, not reinforcement.

The solution is not more aggressive blocking. It is addressing the underlying need the distraction fulfills. Social media provides novelty, social connection, and a sense of being informed. If your work environment does not offer any of these, the drive to seek them elsewhere intensifies. Schedule explicit breaks for checking social media. Maintain social connections through other means during work hours (a Slack channel, a quick text conversation). Read industry news during a designated time block rather than grazing throughout the day.

Reactance theory

Psychological reactance is the motivational state that arises when a person perceives their freedom is being threatened. When you block a website, you are restricting your own freedom, which can paradoxically increase your desire to visit that site. Research on reactance shows that forbidden activities become more attractive specifically because they are forbidden. This is why overly aggressive blocking, where every mildly interesting site is blocked for the entire workday, often leads to abandonment of the blocking system entirely.

The effective approach is moderate blocking. Block the three to five sites that cause the most distraction for you personally. Leave everything else accessible. Allow scheduled break windows where blocks lift. This respects your autonomy while removing the specific triggers that derail your productivity.

Blocking is a tool, not a solution

Website blocking works best as one component of a broader productivity system. If you rely solely on blocking without addressing work structure, task clarity, energy management, and break scheduling, you will end up staring at the blocked page feeling frustrated rather than redirecting your attention to productive work. The block should catch impulsive navigations. The productivity system should ensure you have clear, engaging work to return to when the block fires.

I treat my blocking setup as a safety net, not a cage. It catches the automatic, habitual navigations that happen without conscious intent. When I deliberately want a break, I take one. The block is not there to prevent me from ever visiting Reddit. It is there to prevent me from visiting Reddit when I meant to be debugging a function.

Frequently Asked Questions

What is the most effective way to block distracting websites?
Combining multiple layers produces the best results. Use a hosts file edit or router-level DNS block for system-wide coverage, then add a browser extension like Focus Mode Pro for scheduling and a user-friendly blocked page. The system-level block catches everything; the extension provides the schedule management and user experience that makes the system sustainable.
Can I block websites on my phone without rooting or jailbreaking?
Yes. On iPhone, use Screen Time (Settings, Screen Time, Content and Privacy Restrictions, Web Content). On Android, use Digital Wellbeing's Focus Mode or install a DNS-based blocker like NextDNS, which works as a VPN profile and filters DNS queries without requiring root access. Both approaches are non-destructive and reversible.
Does blocking websites in Chrome incognito mode work?
Hosts file blocking works in incognito mode because it operates at the OS level. Chrome extensions only work in incognito if you explicitly enable them in chrome://extensions by toggling "Allow in Incognito" for each extension. Router-level and DNS-based blocking also work regardless of browser mode.
Will editing my hosts file break anything?
Only the specific domains you add to the block list will be affected. Other sites continue to work normally. If you accidentally block a domain you need, simply remove or comment out that line (prefix it with #) and flush your DNS cache. Keep a backup of your original hosts file before making changes.
How do I block YouTube but still allow specific channels?
Neither hosts file editing nor router-level blocking supports channel-level granularity. You would need a browser extension that supports URL pattern matching, allowing youtube.com/channel/specific-id while blocking the rest of the domain. Some extensions like LeechBlock NG support URL pattern-based rules. Alternatively, subscribe to channels via RSS and consume them in a feed reader during scheduled break times.
What is the difference between 0.0.0.0 and 127.0.0.1 in a hosts file?
Both work for blocking, but 0.0.0.0 is generally preferred. Routing to 127.0.0.1 (localhost) means the browser attempts a connection to your local machine, which may hang for several seconds before failing if a local web server is running. Routing to 0.0.0.0 fails immediately because it is a non-routable address, resulting in faster failure and a better experience.
Can my employer see that I am blocking websites?
Hosts file edits are local to your machine and not visible to your employer unless they have endpoint monitoring software installed. Browser extensions are visible in your browser's extension list. Router-level changes only affect your home network. If you are on a corporate network with managed devices, changes to the hosts file may be reverted by IT management policies.
How long does it take to build a website-blocking habit?
Research on habit formation (Lally et al., 2010) found that the average time to form a new habit is 66 days, with a range of 18 to 254 days. For website blocking, I found that after roughly three weeks of consistent use, the automatic impulse to visit blocked sites decreased significantly. The block still caught occasional attempts, but the frequency dropped from dozens per day to a handful per week.
