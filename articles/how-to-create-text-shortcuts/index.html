Gmail has templates. And if you live in the browser, you need something that works across every website.

Definition: According to Wikipedia, text expansion (also known as text replacement or auto-text) is a software feature that replaces short abbreviations or trigger sequences with longer strings of text. Text expanders are productivity tools used across operating systems and applications to reduce repetitive typing.

macOS Text Replacement Through System Settings

If you use a Mac, the fastest way to start is with the built-in text replacement feature. It works across most native apps including Safari, Notes, Mail, and Messages. The shortcuts sync through iCloud, so they follow you across your Mac, iPhone, and iPad.

Here is how to set it up.

macOS text replacement path

System Settings → Keyboard → Text Replacements

Click the plus button at the bottom left. In the "Replace" field, type your shortcut trigger. In the "With" field, type the expanded text. For example, you might set @@e to expand into your email address, or @@a to expand into your full mailing address.

Choosing Good Trigger Prefixes

The most important decision is your trigger prefix. You want something you would never type naturally. I use a double symbol followed by a letter. Some people prefer a semicolon prefix, a backslash, or a slash. The key rule is to pick one convention and stick with it. Here are some common patterns.

  • @@ followed by a letter, like @@e for email
  • ;; followed by a word, like ;;addr for address
  • \ followed by a keyword, like \sig for signature
  • / followed by a keyword, like /ty for "thank you"

Limitations of macOS Text Replacement

The built-in system has some frustrating constraints. It does not support multi-line text. Whatever you paste into the "With" field gets flattened to a single line. It also does not work in Chrome or Firefox, since those browsers handle text input through their own engines. And there is no way to include formatted text, links, or dynamic content like today's date.

For basic single-line shortcuts in Apple's own apps, it is a perfectly good starting point. But most of us spend the majority of our working hours in a browser, which means you need something more capable.

Windows Text Replacement with AutoHotKey and Built-in Tools

Windows does not ship with a text replacement feature as polished as what macOS offers, but there are two solid approaches. The first is PowerToys, Microsoft's official power-user toolkit. The second is AutoHotKey, a free scripting tool that has been the gold standard for Windows automation since 2003.

PowerToys Quick Accent and Keyboard Manager

PowerToys includes a Keyboard Manager module that can remap keys and create shortcuts, but it is designed for key remapping rather than text expansion. It will not handle the "type a trigger, get expanded text" pattern you are looking for.

For that, AutoHotKey is the right tool.

Setting Up AutoHotKey for Text Expansion

Download AutoHotKey v2 from autohotkey.com. After installation, create a new file with the .ahk extension anywhere on your computer. Open it in a text editor and add your shortcuts using this syntax.

::@@e::michael@example.com
::@@a::123 Main Street, Apt 4B, New York, NY 10001
::@@ty::Thank you for reaching out. I will get back to you within 24 hours.
::@@sig::Best regards,{Enter}Michael Lip{Enter}Zovo

The {Enter} tag inserts a line break, which is something the macOS system cannot do. AutoHotKey also supports variables, conditional logic, and date insertion, making it far more powerful.

To make your shortcuts load automatically when Windows starts, place the .ahk file (or a shortcut to it) in your Startup folder.

Windows startup folder path

File Explorer → Shell:startup

Or press Win+R → type shell:startup → Enter

AutoHotKey Advanced Patterns

Where AutoHotKey really shines is in dynamic expansion. You can insert today's date, the current time, or even pull content from the clipboard. For managing copied content, read our clipboard history guide.

::@@date::
{
    SendInput FormatTime(, "MMMM d, yyyy")
}

::@@cbox::
{
    SendInput "[ ] Task item{Enter}[ ] Another task{Enter}[ ] Third task"
}

The downside is that AutoHotKey only works on Windows, and it operates at the OS level. If you work across multiple machines or primarily in a browser, you will want a browser-based solution as well.

Google Docs Autocorrect and Custom Substitutions

Google Docs has its own text substitution system that most people never discover. It is buried in the preferences menu and it works independently of your operating system. Every substitution you create syncs with your Google account, so it works on any computer where you use Google Docs.

Google Docs substitutions path

Tools → Preferences → Substitutions tab

The interface is straightforward. In the "Replace" column, type your trigger. In the "With" column, type the expanded text. Google Docs comes with a handful of built-in substitutions, like converting (c) to the copyright symbol and --> to an arrow character.

Practical Substitutions for Google Docs

I have found that Google Docs substitutions work best for phrases you use frequently in documents specifically. Some examples from my own setup.

  • /tl expands to "the long-term implications of this approach"
  • /imo expands to "In my assessment, based on the available data,"
  • /rev expands to "This section requires further review before finalization."
  • /fyi expands to "For reference, the supporting documentation is available at"

What Google Docs Substitutions Cannot Do

Like macOS text replacement, Google Docs substitutions are limited to plain text on a single line. You cannot insert formatted text, links, images, or multi-line content. The substitutions only work inside Google Docs itself, not in Google Sheets, Google Slides, or any other application. And there is a soft limit of around 200 substitutions before performance can degrade.

Still, if you write long documents regularly, even 20 or 30 well-chosen substitutions can save significant time.

Gmail Canned Responses and Templates

Email is where most professionals do their heaviest repetitive typing. Gmail addressed this with a templates feature (formerly called Canned Responses) that lets you save and insert entire email drafts with a few clicks.

Enabling Gmail Templates

Enable templates in Gmail

Settings (gear icon) → See all settings → Advanced tab

Find "Templates" → Enable → Save Changes

Once enabled, you can save any draft as a template. Compose a message with the text you want to reuse, then click the three-dot menu at the bottom of the compose window and choose Templates, then Save draft as template. Give it a descriptive name.

To insert a template, start a new compose window, click the three-dot menu, hover over Templates, and select the one you want. The template text replaces whatever is currently in the compose window (or inserts into the body if you already have content).

The Gaps in Gmail Templates

Gmail templates are full-featured in terms of formatting. They support rich text, links, images, and attachments. But they only work inside Gmail's compose window. They do not help you in any other context, and inserting them requires multiple clicks through nested menus. There is no keyboard shortcut to invoke a template by name, which slows things down compared to a true text expansion tool.

Slack Shortcuts and Saved Replies

Slack added a "saved replies" feature for Slack Business+ and Enterprise Grid plans, but even on free plans there are ways to speed up repetitive messaging.

Slackbot Custom Responses

In Slack workspaces where you have admin access, you can configure Slackbot to respond to specific trigger phrases. This is not the same as text expansion, but it can serve a similar purpose for team-wide information. Navigate to your workspace settings, find Slackbot, and add custom responses that trigger when someone types a specific phrase.

Slack Slash Commands and Workflows

For personal text shortcuts in Slack, the built-in options are limited. Slack's message field does not support OS-level text replacement on most configurations. The text cursor in Slack runs through Electron's Chromium engine, which means OS-level text replacement (macOS System Settings or AutoHotKey) often does not trigger correctly.

This is one of the primary reasons browser-based text expanders are valuable. They inject text at the browser or Chromium level, which means they work in Slack's web app, desktop app, and every other Electron-based tool.

Practical Slack Shortcuts Without Extensions

If you are not ready to install a text expander, you can still reduce repetitive typing in Slack through a few techniques. Pin frequently shared messages to channels. Use the bookmark bar in channels to save links you share often. Create a private channel called "clipboard" where you paste text blocks you reuse, making them searchable and easy to copy. These are workarounds, but they help.

Building a Personal Shortcut Library

Having the tools is one thing. Knowing what to shortcut is another. I have seen people set up a text expander, create three shortcuts, and then never add more because they do not know what else to include. Here is a systematic approach.

Start With the Repetition Audit

For one week, keep a note open on your phone or desktop. Every time you catch yourself typing something you have typed before, jot it down with a tally mark. Do not try to be thorough. Just note the ones you catch in the moment. By the end of the week, you will have a clear picture of your highest-value shortcuts.

The Priority Tiers

I organize my shortcuts into tiers based on frequency and time saved per expansion.

Tier 1 (add immediately) covers items you type more than five times per day. These include your email address, phone number, common greetings, and sign-offs. Each one is short, but the sheer frequency makes the savings significant.

Tier 2 (add in the first week) covers longer text blocks you type several times per week. Standard replies to common questions, your mailing address, project URLs, meeting links, status update templates, and invoice boilerplate all belong here.

Tier 3 (add over time) covers situational expansions you use a few times per month but that are long enough to justify the shortcut. Legal disclaimers, terms of service excerpts, detailed process explanations, and troubleshooting instructions fit this tier.

Multi-Line and Formatted Text Expansion

Single-line shortcuts are useful for quick phrases, but the real time savings come from multi-line expansions. A three-paragraph email reply, a code block with proper indentation, a formatted status update. These are the expansions that turn minutes of typing into a single trigger word.

Multi-Line Expansion in AutoHotKey

AutoHotKey handles multi-line text through the {Enter} tag within send commands or through continuation sections.

::/status::
{
    SendInput "Project Status Update{Enter}"
    SendInput "---{Enter}"
    SendInput "Completed: [items]{Enter}"
    SendInput "In Progress: [items]{Enter}"
    SendInput "Blocked: [items]{Enter}"
    SendInput "Next Steps: [items]"
}

This gives you a structured template every time you type /status. You fill in the brackets with the specifics, which is far faster than typing the structure from scratch.

Rich Text Expansion

Some text expanders support rich text, meaning they can insert bold, italic, links, and even images. This is particularly useful for email signatures, formatted responses, and any context where plain text is not sufficient.

The tradeoff with rich text expansion is compatibility. Not every text field on every website supports rich text insertion. Some fields strip formatting, others break in unexpected ways. In my experience, plain text expansion works reliably in 99% of text fields, while rich text expansion works in about 80%. For most use cases, plain text with a clear structure (using line breaks and simple markers) is the more reliable choice.

Dynamic Content in Expansions

The most advanced text expanders support dynamic variables. The most common ones are date and time insertion. Imagine a shortcut /today that always inserts today's date in your preferred format, or /week that inserts the current week number.

Other dynamic options include clipboard content insertion (expand a shortcut that includes whatever you last copied), cursor positioning (place the cursor at a specific point within the expanded text so you can start typing immediately), and fill-in fields (prompt you to fill in blanks before the expansion completes).

These features are powerful, but they also add complexity. I recommend starting with simple static shortcuts and adding dynamic features only when you find specific use cases that justify them.

Frequently Asked Questions

Will text shortcuts conflict with each other across different tools?

Generally no. macOS text replacement, Google Docs substitutions, and browser extensions all operate in separate scopes. macOS replacement triggers in native apps, Google Docs substitutions trigger in Google Docs, and a Chrome extension triggers in the browser. The only potential conflict is if you use the same trigger prefix in multiple tools and happen to use Google Docs in Chrome, where both the Docs substitution and the extension could fire. To avoid this, use distinct prefixes for each tool or rely on a single browser-based expander for all your Chrome-based work.

How many shortcuts is too many?

I currently maintain around 60 shortcuts and have never felt overwhelmed. The naming convention is what makes it manageable. If you use a consistent prefix system, you can scale to over a hundred shortcuts without confusion. The practical limit is your ability to remember the triggers, which is why category prefixes matter. That said, a well-chosen set of 20 shortcuts covers the vast majority of repetitive typing for most people.

Do text expander extensions see everything I type?

Browser extensions that monitor text input technically have access to the text you type on web pages. This is a valid privacy consideration. The important factors are whether the extension sends data externally (check the privacy policy and permissions) and whether it requests more permissions than necessary. Text Expander Pro stores shortcuts locally in Chrome's extension storage and does not transmit data to external servers. You can verify this by checking the extension's permissions in Chrome's extension management page.

Can I sync shortcuts across multiple computers?

macOS text replacements sync through iCloud. AutoHotKey scripts can be stored in a cloud folder like Dropbox or OneDrive. Google Docs substitutions sync with your Google account. Chrome extensions that store data in Chrome's sync storage will sync across any Chrome installation where you are signed in with the same Google account. The sync capabilities vary by tool, so check the documentation for your specific setup.

What if a shortcut triggers when I do not want it to?

This is why trigger prefix choice matters so much. If your trigger for email is just em, it will fire every time you type a word that starts with "em" like "email" or "emphasis." Using a prefix like /em or @@em virtually eliminates false triggers because those character combinations do not appear in normal English text. Most text expanders also require a delimiter (like a space or tab) after the trigger before they expand, which adds another layer of protection.

Are there text expansion tools for mobile devices?

iOS has built-in text replacement through Settings, then General, then Keyboard, then Text Replacement. These sync with macOS through iCloud. Android has limited built-in options, but apps like Texpand and Textpansion fill the gap. For mobile, the built-in options are usually sufficient since you tend to type shorter messages on phones.

Should I use text shortcuts for passwords?

Absolutely not. Text expansion tools store shortcuts in plain text, and a trigger that expands into a password creates a serious security risk. Anyone with access to your extension settings or AutoHotKey script file could see your passwords in plain text. Use a dedicated password manager for credentials. Text shortcuts are for non-sensitive, frequently repeated text only.
