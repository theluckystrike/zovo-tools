How UPC Codes Work

The Universal Product Code (UPC) is a barcode symbology developed by George Laurer at IBM in 1973. It was first used commercially in 1974 when a pack of Wrigley's Juicy Fruit gum was scanned at a Marsh Supermarket in Troy, Ohio. Today, UPC barcodes appear on virtually every retail product sold in North America.

A UPC-A barcode encodes 12 numerical digits. The structure breaks down as follows:

  • Digit 1: Number system character. Indicates the product category (0 or 1 for regular products, 2 for weighted items, 3 for pharmaceuticals, etc.)
  • Digits 2-6: Manufacturer code. Assigned by GS1 (formerly the Uniform Code Council).
  • Digits 7-11: Product code. Assigned by the manufacturer to identify the specific item.
  • Digit 12: Check digit. Calculated using the Modulo 10 algorithm to verify scanning accuracy.

The barcode itself consists of 30 black bars and 29 white spaces, plus start, center, and end guard patterns. Each digit is represented by a specific pattern of two bars and two spaces that span seven modules (units of width). Scanners read the relative widths of bars and spaces to decode the number.

For retail products, EAN-13 is the global standard maintained by GS1. UPC-A is a subset of EAN-13 (any UPC-A code can be expressed as EAN-13 by adding a leading zero). Code 128 is the most versatile linear barcode and is widely used in supply chain management. Code 39 is simpler to implement but produces wider barcodes.

Check Digit Calculation

The check digit is the final digit of a UPC or EAN code. It exists to catch scanning and manual entry errors. The calculation follows the Modulo 10 algorithm:

  1. Starting from the first digit, add up all digits in odd positions (1st, 3rd, 5th...) and multiply the sum by 3.
  2. Add up all digits in even positions (2nd, 4th, 6th...).
  3. Add the two results together.
  4. The check digit is the number that, when added to this total, produces a multiple of 10. Formally: (10 - (total % 10)) % 10.

Example: For UPC-A value 03600029145 (11 digits):

  • Odd positions: 0 + 6 + 0 + 2 + 1 + 5 = 14 × 3 = 42
  • Even positions: 3 + 0 + 0 + 9 + 4 = 16
  • Total: 42 + 16 = 58
  • Check digit: (10 - (58 % 10)) % 10 = (10 - 8) % 10 = 2
  • Full UPC: 036000291452

Usage Guide

Follow these steps to generate a barcode:

  1. Select the barcode type. Choose UPC-A for US retail products, EAN-13 for international retail, Code 128 for alphanumeric data, or Code 39 for government and industrial applications.
  2. Enter the value. For UPC-A, enter 11 digits (the check digit is calculated for you) or all 12 digits. For EAN-13, enter 12 or 13 digits. For Code 128 and Code 39, enter any valid text.
  3. Adjust dimensions. Set bar width (1-6 px), bar height (30-300 px), and choose whether to display human-readable digits below the bars.
  4. Generate. Click the generate button to render the barcode on canvas.
  5. Download or print. Export as PNG (raster, good for screens) or SVG (vector, ideal for print). Use the print button for a clean print layout.

For bulk workflows, switch to the Batch Generation tab. Enter one value per line, select the barcode type, and generate all barcodes at once.

Browser Compatibility: This tool uses the Canvas API and is compatible with Chrome 60+, Firefox 55+, Safari 11+, Edge 79+, and all modern mobile browsers. Internet Explorer is not supported.
