About This Tool

by Michael Lip, this Fibonacci sequence generator uses BigInt arithmetic for exact calculation of large Fibonacci numbers. It supports sequences up to 100 terms with full precision, golden ratio convergence analysis, and a CSS-based Fibonacci spiral visualization.

This tool was, coded, and tested by human developers at Zovo.one. All calculations verified against OEIS A000045 (The On-Line Encyclopedia of Integer Sequences). No generative intelligent was used in building this tool.

Browser Compatibility

Works on Chrome 134+, Firefox 128+, Safari 18+, Edge 134+. BigInt support required for exact large number calculations.
