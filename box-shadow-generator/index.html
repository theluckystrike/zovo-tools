Frequently Asked Questions

What is CSS box-shadow?▾

The CSS box-shadow property adds one or more shadow effects around an element's frame. Each shadow is described by horizontal and vertical offsets, optional blur and spread radii, and a color. You can apply multiple shadows by separating them with commas, and use the inset keyword to create inner shadows that appear inside the element's border.

How do I create multiple shadow layers?▾

Click the "Add Layer" button to create additional shadow layers. Each layer has independent controls for horizontal offset, vertical offset, blur radius, spread radius, color, opacity, and an inset toggle. In CSS, multiple shadows are separated by commas in the box-shadow property. The first shadow in the list appears on top visually.

What is neumorphism?▾

Neumorphism (or soft UI) is a design trend that creates a soft, extruded appearance by combining two box shadows: a light-colored shadow on one side and a dark shadow on the opposite side. The effect works best when the element's background color is very similar to the page background, creating the illusion that the element is raised or pressed into the surface.

What is the difference between box-shadow and text-shadow?▾

Box-shadow applies shadows to an element's rectangular box frame (the entire element), while text-shadow applies shadows only to the text characters within an element. Text-shadow has a simpler syntax with only offset-x, offset-y, blur-radius, and color — it does not support the spread radius or inset keyword that box-shadow offers.

How does the spread radius work?▾

The spread radius is the fourth numeric value in box-shadow. Positive values cause the shadow to expand outward, making it larger than the element. Negative values cause the shadow to shrink inward, making it smaller. A value of 0 means the shadow is the same size as the element before blur is applied. Spread is useful for creating tight, defined shadows or border-like effects.

Can I use inset shadows?▾

Yes. Each shadow layer has an inset toggle that changes it from an outer shadow to an inner shadow. Inset shadows render inside the element's border, creating an embossed, debossed, or sunken look. You can freely mix inset and outer shadows on the same element to create complex depth effects like neumorphism.
