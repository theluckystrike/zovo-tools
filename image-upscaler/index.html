About This Image Upscaler

Batch mode lets you queue multiple images and process them all with the same settings, which is useful when preparing a set of thumbnails or low-resolution assets for print or high-DPI displays.

How Image Interpolation Works

When you enlarge an image, new pixels be created between the existing ones. what color should those new pixels be? Each interpolation algorithm answers this differently.

  • Nearest Neighbor simply copies the color of the closest existing pixel. This is the fastest method and preserves hard edges perfectly, making it pixel art, sprites, and retro game graphics. The result looks blocky at large scales, which is often the desired effect.
  • Bilinear Interpolation looks at the four nearest pixels and blends their colors based on distance. Pixels closer to the sample point contribute more to the final color. This produces smooth gradients but can look blurry on fine details. It is a good balance of speed and quality for quick previews.
  • Bicubic Interpolation extends the sampling window to 16 pixels (a 4x4 grid) and uses a cubic polynomial to weight each one. The result is noticeably sharper than bilinear, with better edge definition. This is the standard method used by most photo editors, including Photoshop's default resize.
  • Lanczos Interpolation uses a sinc function windowed by a Lanczos kernel (3 lobes). It samples a wider area and preserves the most high-frequency detail, producing the sharpest results of any classical method. The tradeoff is slight ringing artifacts near very hard edges, and it takes longer to compute.

For a deeper mathematical treatment, see the Wikipedia article on Lanczos resampling and the Bicubic interpolation page.

Choosing the Right Algorithm

Your choice depends on the image content and what you plan to do with the output.

For pixel art and icons, always use Nearest Neighbor. Any smoothing method will blur the intentional pixel boundaries and ruin the aesthetic. Scale by an integer factor (2x, 3x, 4x) to keep every pixel perfectly aligned.

For photographs and natural images, Lanczos gives the best visual quality. If processing time is a concern (for example, in batch mode with many large images), Bicubic is a close second with faster execution.

For vector-like graphics such as diagrams, charts, or text rendered as images, Bicubic is often the best fit - sharp enough to keep lines clean without the ringing artifacts Lanczos can introduce around high-contrast edges.

If you just need a quick preview before committing to a final render, Bilinear is fast and gives you a reasonable approximation of the output.

Post-Processing Explained

After upscaling, you can optionally apply post-processing filters to refine the result.

Sharpening uses an unsharp mask technique: the image is blurred with a small Gaussian kernel, then the difference between the original and blurred version is amplified and added back. This improves edges and fine detail without introducing noise. It is especially useful after Bilinear upscaling, which tends to soften the image.

Noise Reduction applies a 3x3 median filter. For each pixel, it looks at the surrounding 3x3 neighborhood, sorts the values, and picks the middle one. This removes salt-and-pepper noise and compression artifacts while preserving edges better than a mean blur. It works well on JPEG source images that have block artifacts.

Brightness and Contrast adjustments are straightforward linear transformations applied to each color channel. Brightness adds or subtracts a constant value, while contrast scales the difference from mid-gray (128). These let you compensate for images that become slightly washed out or dark after upscaling.

See the MDN Canvas API documentation for more on pixel manipulation in the browser.

Technical Details and Limits

All processing uses the HTML5 Canvas getImageData and putImageData APIs to read and write individual pixels. The interpolation algorithms are implemented in plain JavaScript, operating directly on the RGBA byte arrays.

Maximum recommended output dimensions depend on your browser and device. Most modern browsers support canvas sizes up to around 16,384 x 16,384 pixels, though memory may become an issue above 8,000 x 8,000 on devices with limited RAM. If an upscale would exceed 16,000 pixels in either dimension, the tool will warn you.

Lanczos processing on a 4000x3000 source image at 4x scale produces a 16000x12000 output - roughly 768 million pixel samples with the 3-lobe kernel. On a modern laptop, expect this to take 10-30 seconds. The progress bar updates throughout so you can track the computation.

This tool works in all modern browsers - Chrome 134, Firefox 125, Safari 14+, and Edge 134. It requires JavaScript enabled and uses Canvas 2D context, Web Workers (where supported), and the File API. Internet Explorer is not supported.

Frequently Asked Questions

What interpolation method should I use for upscaling?

For pixel art or retro graphics, use Nearest Neighbor to keep crisp edges. For photographs, Lanczos produces the sharpest results with minimal ringing. Bicubic is a good all-around choice for most images, and Bilinear is fastest for quick previews.

Is this image upscaler free and private?

Yes. This tool runs entirely in your browser using JavaScript and the Canvas API. Your images are never uploaded to any server. All processing happens locally on your device, making it completely free, private, and secure.

How large can I upscale an image?

You can upscale images up to 4x their original dimensions using the preset buttons, or enter custom width and height values for any target size. Very large output images (above 8000px) may be slow depending on your device and available memory.

What is the difference between Bicubic and Lanczos interpolation?

Bicubic samples 16 surrounding pixels using a cubic polynomial kernel, producing smooth results. Lanczos uses a sinc-based kernel with a wider sampling window (3 lobes), preserving more high-frequency detail for sharper edges, though it can introduce slight ringing artifacts around hard edges.

Can I upscale multiple images at once?

Yes. Enable Batch Mode to upload and process multiple images with the same upscaling settings. Each image is processed sequentially and you can download them individually once complete.
