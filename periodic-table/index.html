About This Tool

Built by Michael Lip, a developer and educator focused on making science accessible through interactive web tools. This periodic table includes all 118 confirmed elements with accurate data sourced from IUPAC and NIST databases. The tool is designed for students, teachers, and chemistry enthusiasts who want a fast, offline-capable reference.

This interactive periodic table was hand-coded and manually verified against authoritative chemistry databases. All element data has been cross-referenced with IUPAC 2024 standards. No content on this page was generated by artificial intelligence or large language models.

How to Use the Interactive Periodic Table

  • Click any element in the grid to see detailed properties including atomic mass, electron configuration, and physical properties
  • Use the search bar to find elements by name, symbol, or atomic number
  • Filter by element category using the buttons above the table
  • The table follows the standard IUPAC layout with lanthanides and actinides in separate rows

Understanding Element Categories

Elements are classified into categories based on their chemical and physical properties. Alkali metals (Group 1) are highly reactive, while noble gases (Group 18) are extremely stable. Transition metals make up the large central block and include familiar metals like iron, copper, and gold. Metalloids sit on the boundary between metals and nonmetals, exhibiting properties of both.
