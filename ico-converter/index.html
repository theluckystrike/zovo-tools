# Understanding the ICO Format

    
The ICO file format was introduced by Microsoft for Windows application icons and later adopted as the standard web favicon format. A single ICO file is a container holding multiple image resolutions.

    

      

        
File Structure

        
An ICO file has a 6-byte header (magic bytes, image count), followed by 16-byte directory entries for each image, and then the raw image data (BMP without file header, or embedded PNG).

      

      

        
BMP vs PNG Encoding

        
Traditional ICO files use BMP encoding (32-bit BGRA with an AND mask). Modern ICO files can embed PNG data for larger sizes (64px+), reducing file size significantly. This tool uses both: BMP for 16-48px, PNG for 64px+.

      

    

  


  
  

    
# Complete Favicon Guide

    

      

        
favicon.ico (16/32/48px)

        
The classic favicon file. Place it in your site root. Browsers check for /favicon.ico automatically. The ICO file contains 16x16 (tab icon), 32x32 (shortcut), and 48x48 (Windows site) sizes.

      

      

        
PNG favicons (32/192px)

        
Modern browsers prefer PNG favicons specified via <link> tags. Use 32x32 for desktop browsers and 192x192 for Progressive Web Apps.

      

      

        
Apple Touch Icon (180px)

        
Required for iOS home screen bookmarks. Apple devices use a 180x180 PNG specified by <link rel="apple-touch-icon">. iOS will round corners and add effects automatically.

      

      

        
Android Chrome (192/512px)

        
Android uses icons defined in the Web App Manifest. Standard sizes are 192x192 and 512x512 for add-to-homescreen and splash screens.

      

    

  


  
  

    
# Browser Compatibility

    
This converter tool works in all modern browsers with Canvas API support. The generated ICO files and PNG favicons are compatible with:

    

      

        
Chrome / Edge / Firefox

        
Full support for ICO favicons, PNG favicons, SVG favicons, and Web App Manifest icons. All generated formats work without issues.

      

      

        
Safari / iOS

        
Supports ICO and PNG favicons. Requires apple-touch-icon link tag for home screen icons. Safari does not support SVG favicons in the tab bar.

      

      

        
Internet Explorer / Legacy

        
IE 11 and older only support ICO format favicons. This is why generating a traditional favicon.ico file remains important for full compatibility.

# Frequently Asked Questions

    

      

        
What is an ICO file?▼

        
An ICO file is a container format used for icons on Windows and as favicons on the web. A single ICO file can contain multiple image sizes (e.g., 16x16, 32x32, 48x48, 256x256), allowing the operating system or browser to select the most appropriate resolution. The format was originally developed by Microsoft and uses BMP or PNG encoding internally.

      

      

        
What image formats can I upload?▼

        
You can upload PNG, JPG/JPEG, WebP, and SVG files. For best results, use a square PNG image with a transparent background, ideally 512x512 pixels or larger. SVG files work well because they scale without quality loss.

      

      

        
What sizes does the converter generate?▼

        
The tool generates favicon sizes at 16x16, 32x32, 48x48, 64x64, 128x128, and 256x256 pixels. It also produces an Apple Touch Icon at 180x180, and Android Chrome icons at 192x192 and 512x512. The combined ICO file contains the 16, 32, 48, 64, 128, and 256 pixel versions.

      

      

        
Is my image uploaded to a server?▼

        
No. All image processing happens entirely in your browser using the HTML5 Canvas API. Your images are never sent to any server. The ICO file binary is constructed client-side using JavaScript ArrayBuffers. You can verify this by using the tool offline after the page has loaded.

      

      

        
How does the ICO file format work internally?▼

        
An ICO file starts with a 6-byte header specifying the file type and number of images. Each image entry has a 16-byte directory entry containing its dimensions, color depth, and data offset. The actual image data follows, encoded either as BMP (without the file header) or as embedded PNG.

      

      

        
What HTML tags do I need for favicons?▼

        
At minimum, add <link rel="icon" href="/favicon.ico" sizes="any"> for the classic favicon and <link rel="icon" type="image/png" href="/favicon-32x32.png" sizes="32x32"> for modern browsers. For Apple devices, add <link rel="apple-touch-icon" href="/apple-touch-icon.png">. The tool generates a complete HTML snippet with all recommended tags.
