Understanding the ICO Format

The ICO (icon) file format was introduced by Microsoft for use as program icons in Windows. It has since become the de facto standard for website favicons — the small icons displayed in browser tabs, bookmarks, history lists, and address bars. Despite being decades old, ICO remains the most universally compatible icon format across browsers and operating systems.

Why Multi-Size ICO Files Matter

A defining feature of the ICO format is its ability to contain multiple images at different resolutions within a single file. When an operating system or browser needs to display an icon, it selects the size that best matches the current display context. A browser tab typically uses 16x16 pixels, while a Windows desktop shortcut uses 48x48 pixels, and modern high-DPI displays may request 256x256. Without multiple sizes embedded, the system must scale a single image up or down, often resulting in blurry, pixelated, or aliased icons.

ICO File Structure

An ICO file begins with a 6-byte header containing a reserved field, the image type (1 for icons, 2 for cursors), and the count of embedded images. This is followed by a directory of image entries, each specifying width, height, color depth, and the offset to the image data. The actual image data can be stored as BMP (without the BMP file header) or as embedded PNG. Modern ICO files typically use PNG encoding for 256x256 and above to achieve better compression, while smaller sizes use BMP with 32-bit RGBA for broad compatibility.

Favicons in Modern Web Development

While modern browsers support PNG and even SVG favicons through <link> tags, the ICO format remains important for maximum backward compatibility. Best practice is to provide a favicon.ico in the site root with at least 16x16 and 32x32 sizes, supplemented by PNG favicons for Apple Touch icons and Android manifest icons. The ICO file serves as the universal fallback that every browser and web crawler recognizes, including legacy systems and specialized crawlers that check for /favicon.ico automatically.

Common Use Cases & Tips

🌐 Website Favicons

Create a multi-size ICO file for your website favicon. The recommended preset includes 16x16, 32x32, and 48x48 for comprehensive browser and operating system support.

💻 Desktop Application Icons

Windows applications use ICO files for their program icons. Include all sizes up to 256x256 for sharp rendering on standard and high-DPI displays alike.

🗁 Bookmark and Shortcut Icons

When users bookmark your site or pin it to their taskbar, browsers use the favicon. A crisp multi-size ICO ensures your brand looks professional everywhere.

🛠 Custom Folder Icons

Create custom icons for Windows folders, file type associations, or desktop shortcuts. The ICO format is required for all these use cases on Windows.

🔎 Tips for Best Results

Start with a square PNG at 256x256 or larger with a transparent background. Simple, bold designs with high contrast scale down better to 16x16 where pixel count is very limited.

⚠ Troubleshooting Blurry Icons

If small sizes look blurry, simplify your design. Icons at 16x16 have only 256 total pixels, so intricate artwork with fine detail cannot render well at that scale.

Frequently Asked Questions

What is the ICO file format?▼
ICO is a file format used for icons in Microsoft Windows and for favicons on the web. An ICO file can contain multiple images at different sizes and color depths, allowing the operating system or browser to select the most appropriate version for any display context. The format supports 32-bit color with full alpha transparency.
Why should I use a multi-size ICO file?▼
Multi-size ICO files contain the same icon at multiple resolutions (e.g., 16x16, 32x32, 48x48, 256x256). This ensures your icon looks sharp in every context — browser tabs use 16x16, the Windows taskbar uses 32x32, and desktop shortcuts use 48x48 or larger. Without multiple sizes, the system must scale a single image, often producing blurry or pixelated results.
What are the favicon requirements for websites?▼
For website favicons, include at minimum 16x16 and 32x32 pixel versions in your ICO file. Place the file as favicon.ico in your site's root directory or reference it with a <link> tag. For best results, also include 48x48 for Windows site pinning. Consider providing additional PNG favicons for Apple Touch icons (180x180) and Android devices (192x192).
Does the converter preserve transparent backgrounds?▼
Yes. If your source image has a transparent background (such as a PNG with an alpha channel), the transparency is fully preserved in the generated ICO file. The converter uses 32-bit RGBA color depth, which supports full alpha transparency. This is essential for icons that need to blend seamlessly against any background.
ICO vs PNG favicon — which should I use?▼
ICO is the traditional format with the broadest compatibility, supported by every browser including all versions of Internet Explorer. PNG favicons work in modern browsers and offer better compression for larger icon sizes. For maximum compatibility, use ICO for the primary favicon.ico and provide PNG alternatives via <link> tags for high-resolution displays and Apple/Android devices.
Which browsers support ICO favicons?▼
ICO favicons are supported by all major browsers: Chrome, Firefox, Safari, Edge, and Opera. ICO is the only favicon format recognized by legacy Internet Explorer versions. Modern browsers additionally accept PNG and SVG favicons, but ICO remains the safest universal choice. Web crawlers and social media platforms also look for favicon.ico in the site root by default.
