About CSS Gradients

CSS gradients let you display smooth transitions between two or more colors. They are generated by the browser, so they look great at any resolution. This tool supports linear, radial, and conic gradient types with any number of color stops.

Linear gradients transition along a straight line defined by an angle. Radial gradients radiate from a center point outward. Conic gradients transition around a center point. All three can be made repeating for pattern effects.
