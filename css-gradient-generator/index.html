CSS gradients are one of the most versatile styling tools available in modern web design. They allow you to create smooth transitions between two or more colors without using image files, which means faster page loads, resolution independence, and easy customization. From subtle background textures to bold hero sections, gradients add depth, visual interest, and a professional touch to any website. This generator supports all three types of CSS gradients: linear, radial, and conic, giving you complete control over every aspect of the gradient's appearance.

Linear Gradients

Linear gradients create a smooth color transition along a straight line. You control the direction of the gradient by setting an angle from 0 to 360 degrees. At 0 degrees, the gradient flows from bottom to top. At 90 degrees, it flows from left to right. At 180 degrees, from top to bottom. You can set any angle in between for diagonal gradients. Linear gradients are the most commonly used gradient type on the web, perfect for backgrounds, buttons, headers, and decorative elements. The angle slider provides real-time feedback, and you can see exactly how the direction affects the gradient as you adjust it.

Radial Gradients

Radial gradients create a color transition that radiates outward from a central point. This generator gives you control over the shape (circle or ellipse) and the position of the center point using X and Y sliders. A circular radial gradient spreads evenly in all directions, while an elliptical gradient stretches to fill the element's shape. By adjusting the center position, you can create off-center spotlight effects, vignettes, and other creative patterns. Radial gradients are excellent for creating depth, glow effects, and focal points in your designs. The live preview updates instantly as you move the position sliders, making it easy to find the perfect placement.

Conic Gradients

Conic gradients create color transitions that sweep around a center point, like the sweep of a clock hand. They are sometimes called angular gradients and are the newest addition to the CSS gradient specification. This tool lets you control the starting angle (0 to 360 degrees) and the center position (X and Y) of the conic gradient. Conic gradients are particularly effective for creating pie chart effects, color wheels, and dynamic radial patterns. When combined with multiple color stops, conic gradients can produce effects that are difficult or impossible to achieve with linear or radial gradients alone.

Draggable Color Stops

The color stop bar is the heart of the gradient editor. Each color stop is represented by a draggable handle on the bar. Click anywhere on the bar to add a new stop at that position. Drag any handle to reposition it. Click a handle to select it, then change its color using the color picker in the controls below. You can have between 2 and 10 color stops, allowing you to create simple two-color transitions or complex multi-stop gradients. Each stop shows its color, hex value, and percentage position, giving you precise control over the gradient's composition. To remove a stop, click the delete button next to it in the stop list.

Frequently Asked Questions

What types of CSS gradients can I create with this tool?

This tool supports all three CSS gradient types. Linear gradients create straight-line color transitions with angle control from 0 to 360 degrees, allowing you to set the direction of the gradient in any direction. Radial gradients create circular or elliptical color transitions with customizable shape (circle or ellipse) and center position. Conic gradients create color transitions that sweep around a center point, like a clock hand, with both starting angle and center position controls. You can switch between types at any time and your color stops are preserved.

How do I add or remove color stops?

Click anywhere on the gradient stop bar to add a new color stop at that position. The new stop will inherit a color that blends with the surrounding stops. To remove a stop, click the X (delete) button next to that stop's controls in the list below the bar. You must have at least 2 stops, so the delete button is hidden when only two remain. You can have a maximum of 10 stops. Drag any stop handle along the bar to reposition it, and click a handle to select it and edit its color using the color picker in the controls.

What are vendor prefixes and should I use them?

Vendor prefixes (-webkit-, -moz-, -o-) were historically required for CSS gradients to work correctly across different browsers during the early adoption of the CSS gradient specification. Modern browsers now fully support the standard unprefixed gradient syntax, meaning vendor prefixes are no longer necessary for the vast majority of users. However, if your project needs to support very old browser versions (such as Safari 6 or older Android browsers), you can toggle on vendor prefixes to include them in the generated output. For most new projects targeting current browsers, leaving vendor prefixes off is recommended for cleaner, shorter CSS.

The random gradient button generates an entirely new gradient configuration using randomized parameters. It randomly selects a gradient type (linear, radial, or conic), generates between two and five color stops with randomly chosen colors and positions, and sets appropriate type-specific parameters such as angle for linear gradients or shape and position for radial gradients. The random colors are generated to be visually interesting while covering a wide range of the color spectrum. It is a great way to discover unexpected and beautiful color combinations that you might not have created manually. If you find a random gradient you like, you can fine-tune it using the controls.
