About Chmod Permissions

Unix/Linux file permissions control access to files and directories. Each file has three permission groups: owner (u), group (g), and others (o). Each group can have read (r=4), write (w=2), and execute (x=1) permissions.

The numeric (octal) notation sums the permission values for each group. For example, 755 means: owner has 7 (4+2+1 = read+write+execute), group has 5 (4+1 = read+execute), and others have 5 (read+execute).
