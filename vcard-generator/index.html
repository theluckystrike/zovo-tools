NFC Tag Information

vCard data can be written to NFC tags for tap-to-share functionality. NFC tags with at least 500 bytes of storage (NTAG215 or NTAG216) are recommended for basic contacts. For contacts with embedded photos, use tags with 4KB+ capacity. The vCard data is written as an NDEF record with MIME type text/vcard. Most modern smartphones (Android 4.0+, iOS 13+) can read NFC vCards natively.

How vCards Work

The vCard format is an open standard for electronic business cards defined by the Internet Engineering Task Force (IETF). Version 3.0 is specified in RFC 2426, and version 4.0 in RFC 6350.

Each vCard file starts with BEGIN:VCARD and ends with END:VCARD. Properties like FN (formatted name), TEL (telephone), EMAIL, ADR (address), and PHOTO store contact data. The format is plain text and human-readable.

vCard files are universally supported. Apple Contacts, Google Contacts, Microsoft Outlook, Thunderbird, and every smartphone platform can import .vcf files. The vCard Wikipedia article provides a thorough overview of the format's history.

Photos can be embedded directly as Base64-encoded data or referenced via URL. For maximum compatibility, embedding the photo ensures it displays even without internet access. Social profiles are stored using the X-SOCIALPROFILE property in vCard 3.0 or the IMPP / URL properties in vCard 4.0.

Frequently Asked Questions

What is a vCard (.vcf) file?▾
A vCard is a standard file format (.vcf) for electronic business cards, defined by RFC 6350. It stores contact information including names, phone numbers, email addresses, physical addresses, photos, and more. Every major contact application and smartphone platform can import vCard files.
Should I use vCard 3.0 or 4.0?▾
Use vCard 3.0 for maximum device compatibility. It works with virtually all contact applications, including older ones. Use vCard 4.0 if your recipients use modern software and you need features like better social profile support and improved internationalization. When in doubt, vCard 3.0 is the safer choice.
Can I embed a photo in the vCard?▾
Yes. Upload a JPEG or PNG image using the photo upload field. The image is converted to Base64 and embedded directly in the vCard file. This means the photo travels with the contact file and displays without needing internet access. Keep photos under 200KB for best compatibility.
How does the QR code work?▾
The QR code encodes your vCard data directly. When scanned with a smartphone camera, the device recognizes the contact data and offers to save it to the address book. QR codes work well on printed business cards, conference badges, and screens. The QR code is generated locally in your browser using the Canvas API.
Is my contact data private?▾
All processing happens entirely in your browser. No names, phone numbers, emails, photos, or any other data leaves your device. The .vcf file and QR code are generated locally using JavaScript. There are no server-side components, analytics trackers, or third-party scripts.
Can I import an existing .vcf file for editing?▾
Yes. Use the Import section to load an existing .vcf file. The parser reads the vCard properties and populates the form fields, allowing you to edit the contact details and re-export. This works with both vCard 3.0 and 4.0 files from any source.
