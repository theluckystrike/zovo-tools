How to Use This Tool

Using this video trimmer is straightforward. Upload a video file by clicking the upload area or dragging and dropping a file onto it. Once loaded, the video player shows your clip and a timeline bar appears below it.

Drag the green handles on the timeline to set your desired start and end points. You can also type exact timestamps into the input fields for precision down to the millisecond. Click "Preview Trim" to play only the selected section, then "Export Trimmed Video" to generate a downloadable WebM file.

Step-by-Step

  1. Click the upload area or drag a video file onto it
  2. Wait for the video to load and the timeline to appear
  3. Drag the left handle to set the start point, or press [ during playback
  4. Drag the right handle to set the end point, or press ] during playback
  5. Click "Preview Trim" to review your selection
  6. Click "Export Trimmed Video" to generate and download the result

Supported Formats

This tool accepts any video format that your browser can play natively. In practice, the most widely supported formats are:

  • MP4 (H.264) — universal support across all modern browsers
  • WebM (VP8/VP9) — native to Chrome, Firefox, and Edge
  • MOV — supported in Safari and most Chromium-based browsers
  • AVI — limited browser support, but works in some configurations

The output format is always WebM, which is a widely compatible, open-source video container format. Most video players, browsers, and social media platforms accept WebM files.

The Export Process

When you click "Export Trimmed Video," the tool performs these steps entirely within your browser:

  1. A hidden <canvas> element is created matching the video's resolution
  2. The video seeks to the start point of your trim selection
  3. A MediaRecorder begins recording the canvas stream
  4. Each frame of the video is drawn to the canvas during playback
  5. Audio from the video is captured alongside the canvas stream
  6. When playback reaches the end point, recording stops
  7. The recorded chunks are assembled into a WebM file for download

This approach means no server-side processing is needed. Your video data stays on your machine at all times.

Tips for Best Results

Keep these suggestions in mind to get the best output from this trimmer:

  • Use MP4 (H.264) or WebM input files for the most reliable playback and seeking.
  • Shorter clips export faster. If you only need a 10-second section from a 2-hour file, the export takes about 10 seconds of real time.
  • The export runs at real-time playback speed, so a 30-second trim takes roughly 30 seconds to process.
  • For precision, use the time input fields rather than the drag handles. They accept millisecond-level values.
  • Preview your trim before exporting to make sure the start and end points are correct.
  • If the exported file seems too large, consider using a dedicated video compressor afterward.

Technical Details

This tool relies on two core browser APIs: the HTMLMediaElement API for video playback and the MediaRecorder API for recording the output.

During export, a <canvas> element is sized to match the video's native resolution. Each frame is drawn using drawImage(), and the canvas stream is captured with captureStream(). The MediaRecorder writes to an array of Blob chunks, which are merged into a single WebM file at the end.

Audio is handled by creating an AudioContext with a MediaElementSourceNode connected to a MediaStreamDestination. The audio track is added to the canvas stream before recording begins, producing a final file with both video and audio.

For more on the underlying web standards, see the WebM format on Wikipedia.

Frequently Asked Questions

Is this video trimmer free to use?

Yes, completely free with no sign-up, no watermarks, and no limits on file size or number of trims. Use it as often as you need.

Does my video get uploaded to a server?

No. All processing happens entirely in your browser using JavaScript and the MediaRecorder API. Your video file never leaves your device.

What video formats are supported for input?

Any format your browser can play natively: MP4 (H.264), WebM (VP8/VP9), MOV, and in some browsers AVI. The most reliable input is MP4.

What is the output format?

The trimmed video is always exported as WebM, using the browser's built-in MediaRecorder API with VP8 or VP9 video codec, depending on your browser.

Are there keyboard shortcuts?

Yes. Press Space to toggle play/pause, [ (left bracket) to set the start point at the current playback position, and ] (right bracket) to set the end point.
