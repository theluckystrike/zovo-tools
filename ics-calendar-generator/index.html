How ICS Files Work

The iCalendar format (file extension .ics) was standardized as RFC 5545 by the Internet Engineering Task Force (IETF). It defines a plain-text format for representing calendar events, to-do items, and free/busy information.

Every ICS file starts with BEGIN:VCALENDAR and ends with END:VCALENDAR. Inside, each event is wrapped in BEGIN:VEVENT / END:VEVENT blocks. Properties like DTSTART, DTEND, SUMMARY, and RRULE define the event details.

The format is universally supported. Google Calendar, Apple Calendar (iCal), Microsoft Outlook, Mozilla Thunderbird, and virtually every calendar application can import .ics files. This makes it the standard interchange format for calendar data.

Recurrence rules (RRULE) follow a structured syntax. For example, RRULE:FREQ=WEEKLY;INTERVAL=2;BYDAY=MO,WE,FR means "every 2 weeks on Monday, Wednesday, and Friday." The iCalendar Wikipedia article provides additional context on the history and adoption of the format.

Frequently Asked Questions

What is an ICS file?▾
An ICS file is an iCalendar file format defined by RFC 5545. It stores calendar event data including title, description, dates, location, recurrence rules, and reminders. ICS files are supported by virtually all calendar applications including Google Calendar, Apple Calendar, Outlook, and Thunderbird.
How do I import an ICS file into Google Calendar?▾
Open Google Calendar, click the gear icon, select Settings, then Import & Export. Click "Select file from your computer", choose your .ics file, select the target calendar, and click Import. You can also use the Google Calendar link generated by this tool to add events directly without downloading a file.
Can I create recurring events with this tool?▾
Yes. This tool supports daily, weekly, monthly, and yearly recurrence patterns. You can set the repeat interval (e.g., every 2 weeks), specify an end date or occurrence count, and for weekly recurrence, choose which days the event should repeat on. The recurrence rules follow the RRULE specification in RFC 5545.
Is my event data sent to a server?▾
No. All processing happens entirely in your browser using JavaScript. The .ics file is generated locally and downloaded directly. No data is transmitted to any server. There are no analytics, cookies, or tracking scripts on this page.
Can I include multiple events in one file?▾
Yes. Add events to the event list, then download them all as a single .ics file. Each event keeps its own title, times, recurrence, reminders, and attendee list. This works well for conference schedules, class timetables, or multi-day trip itineraries.
Which calendar apps support ICS files?▾
Nearly all calendar applications support the ICS format. This includes Google Calendar, Apple Calendar (macOS and iOS), Microsoft Outlook (desktop and web), Mozilla Thunderbird, Yahoo Calendar, Samsung Calendar, and most other calendar apps. The iCalendar format has been the standard since 1998.
