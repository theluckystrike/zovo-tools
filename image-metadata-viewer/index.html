About EXIF Data

EXIF (Exchangeable Image File Format) is a standard originally defined by the Japan Electronic Industries Development Association (JEIDA) for storing metadata in image files. The current version is EXIF 2.32, maintained by CIPA.

When a camera takes a photo, it embeds metadata in the file header. This includes the camera make and model, lens used, exposure settings (aperture, shutter speed, ISO), focal length, date/time, orientation, color space, and optionally GPS coordinates if location services are enabled.

EXIF data is stored in the APP1 marker segment of JPEG files, using a TIFF-based structure of Image File Directories (IFDs). Each IFD contains a series of tagged entries, where each tag has a numeric ID, data type, count, and value.

For the full specification details, see the Wikipedia article on EXIF and the MDN JPEG format reference.

Frequently Asked Questions

What is EXIF data in an image?
EXIF (Exchangeable Image File Format) is a standard for storing metadata inside image files. It includes camera make and model, lens information, aperture, shutter speed, ISO, date and time the photo was taken, GPS coordinates, orientation, color space, and software used for processing. EXIF data is embedded directly in JPEG, TIFF, and some other formats by the camera or phone at the moment the photo is captured.
Does this tool upload my images to a server?
No. All image processing happens entirely in your browser using JavaScript and the File API. Your images never leave your device. The EXIF parser reads the binary data locally. You can verify this by disconnecting from the internet and confirming the tool continues to work normally.
Why should I strip metadata before sharing photos?
Image metadata can contain GPS coordinates (revealing where the photo was taken), camera serial numbers (linking photos to a specific device), timestamps, and software details. Stripping this data before sharing photos online helps protect your privacy and prevents unintentional disclosure of your location or equipment.
What image formats are supported?
This tool supports JPEG (full EXIF parsing including GPS, camera, lens, and thumbnail extraction), PNG (file-level metadata), WebP (basic metadata), and TIFF (EXIF data). JPEG files contain the richest metadata because the EXIF standard was designed primarily for JPEG and TIFF formats. PNG and WebP typically contain much less embedded information.
How do I view GPS coordinates from a photo?
Upload a JPEG photo that was taken with GPS or location services enabled on the camera or phone. If GPS data is present, this tool displays the latitude and longitude in the GPS tab, along with a direct link to view the location on OpenStreetMap. A privacy warning is also shown to alert you that location data is embedded in the file.
Can I compare metadata from two different images?
Yes. Scroll down to the Compare section and upload two images. The tool displays metadata from both in parallel columns, making it straightforward to compare camera settings, dates, GPS locations, and other EXIF fields between the two photos.

About This Tool

The Image Metadata Viewer is a free, privacy-focused tool for extracting and inspecting EXIF metadata embedded in digital photographs and images. Every digital photo taken with a camera or smartphone contains hidden metadata that records the camera make and model, lens used, exposure settings, GPS coordinates, timestamps, and more. This tool reads that data directly in your browser without uploading anything to a server.

Beyond reading metadata, the tool includes a privacy checker that scans for sensitive information such as GPS coordinates, camera serial numbers, and personally identifiable data. For images you plan to share online, the built-in metadata stripping feature re-exports the image through an HTML Canvas element, which discards all EXIF data including location information. The side-by-side comparison mode lets you compare metadata from two different images, useful for verifying camera settings or matching photos to devices.

Built by Michael Lip, this tool uses a custom inline EXIF parser written in JavaScript that reads the binary APP1 marker segment and TIFF-based IFD structure directly from the image file. All processing happens locally in your browser using the File API. No images are ever uploaded, stored, or transmitted to any external server.
