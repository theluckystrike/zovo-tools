How to Use the File Size Converter

Enter a numeric value and select the unit you are converting from. All other units are calculated instantly. Use the toggle at the top to switch between binary (base-2, multiples of 1024) and decimal (base-10, multiples of 1000) standards.

  • Binary (1024) is how operating systems like Windows, macOS, and Linux report storage.
  • Decimal (1000) is how hard drive and SSD manufacturers label capacity.
  • Click the copy button next to any value to copy it to your clipboard.

All calculations run entirely in your browser. No data is sent to any server.

Frequently Asked Questions

What is the difference between binary and decimal file sizes?

Binary (base-2) uses multiples of 1024, which is how operating systems measure storage. Decimal (base-10) uses multiples of 1000, which is how drive manufacturers label capacity. A 1 TB drive appears as about 931 GB in Windows because of this difference.

How many megabytes are in a gigabyte?

In binary, 1 GB = 1,024 MB. In decimal, 1 GB = 1,000 MB. Most operating systems use binary, while storage manufacturers use decimal.

Why does my hard drive show less space than advertised?

Manufacturers use decimal units (1 GB = 1,000,000,000 bytes) while your operating system uses binary units (1 GB = 1,073,741,824 bytes). This converter lets you see the exact difference between the two standards.

What are IEC binary prefixes (KiB, MiB, GiB)?

IEC binary prefixes were introduced to clearly distinguish binary multiples (powers of 1024) from decimal SI prefixes (powers of 1000). 1 KiB = 1024 bytes, 1 MiB = 1,048,576 bytes, 1 GiB = 1,073,741,824 bytes.
