Percentage Formulas

Percentage Change:

Change% = ((New - Old) / |Old|) x 100

Percentage of a Number:

Result = (Percentage / 100) x Number

Percentage Difference:

Diff% = (|V1 - V2| / ((V1 + V2) / 2)) x 100

Reverse Percentage (after increase):

Original = Final / (1 + Percentage/100)

Reverse Percentage (after decrease):

Original = Final / (1 - Percentage/100)

Frequently Asked Questions

How do you calculate percentage change?
Percentage change is calculated as: ((New Value - Old Value) / |Old Value|) x 100. A positive result means a percentage increase, while a negative result means a percentage decrease. For example, going from 50 to 75: ((75-50)/50) x 100 = 50% increase.
What is percentage difference vs percentage change?
Percentage difference compares two values symmetrically, without treating either as the "original." It uses the average of both values as the denominator: |V1-V2| / ((V1+V2)/2) x 100. Percentage change, on the other hand, measures how much one specific value changed relative to its starting point.
What is a reverse percentage calculation?
A reverse percentage calculation finds the original number before a percentage was applied. For example, if a price after a 20% discount is $80, the original price was $80 / (1 - 0.20) = $100. Similarly, if a value after a 15% increase is $115, the original was $115 / (1 + 0.15) = $100.
