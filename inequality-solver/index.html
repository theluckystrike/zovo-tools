What Is an Inequality

An inequality is a mathematical statement that compares two expressions using one of four relational symbols: less than (<), greater than (>), less than or equal to (≤), or greater than or equal to (≥). While an equation states that two expressions are equal, an inequality states that one expression is larger or smaller than another.

The fundamental difference between an equation and an inequality is the nature of their solutions. An equation like 2x + 3 = 7 has one solution (x = 2). An inequality like 2x + 3 < 7 has infinitely many solutions: every number less than 2. The solution to an inequality is a range or set of values, not a single number.

Inequalities use a specific vocabulary. The expression on the left of the inequality sign is the left-hand side, and the expression on the right is the right-hand side. The inequality is "strict" if it uses < or > (the boundary value is not included) and "non-strict" or "weak" if it uses ≤ or ≥ (the boundary value is included).

Key distinction: equations have fixed solutions (points), while inequalities have solution sets (intervals or regions). The boundary point is where the corresponding equation holds true.

Solving Linear Inequalities

A linear inequality contains a variable raised to the first power and can be written in the form ax + b < c (or with any of the four inequality signs). Solving it follows nearly the same process as solving a linear equation, with one critical rule that distinguishes the two.

The Process

  1. Simplify both sides of the inequality if needed (distribute, combine like terms).
  2. Move variable terms to one side and constant terms to the other, using addition or subtraction.
  3. Divide both sides by the coefficient of the variable to isolate it.
  4. If you multiply or divide by a negative number, reverse the inequality sign.

The Negative Multiplication Rule

This is the single most important rule in inequality solving and the source of most student errors. When you multiply or divide both sides of an inequality by a negative number, the inequality sign must be reversed. The reason is straightforward: multiplying by a negative number reverses the order of numbers on the number line.

Consider the true statement 3 < 5. Multiply both sides by -1: -3 and -5. On the number line, -3 is to the right of -5, meaning -3 > -5. The inequality reversed. This happens every time you multiply or divide by a negative, so you must always flip the sign.

The golden rule of inequalities: multiplying or dividing both sides by a negative number reverses the direction of the inequality. This rule must be applied every time, without exception.

Linear Inequality Example

Solve: -2x + 7 ≥ 3. Subtract 7 from both sides: -2x ≥ -4. Divide by -2 (negative, so flip the sign): x ≤ 2. The solution set is all real numbers less than or equal to 2, written in interval notation as (-inf, 2].

Solving Quadratic Inequalities

A quadratic inequality involves a variable raised to the second power: ax² + bx + c compared to zero. Solving these requires a different strategy than linear inequalities because the parabola can cross the x-axis up to two times, creating up to three intervals to consider.

The Sign Analysis Method

  1. Move all terms to one side so the inequality compares to zero.
  2. Solve the corresponding equation (ax² + bx + c = 0) to find the critical points (roots).
  3. Plot the critical points on a number line, dividing it into intervals.
  4. Test a value from each interval in the original expression to determine the sign (positive or negative) in that interval.
  5. Select the intervals where the sign satisfies the inequality.
  6. Include or exclude the endpoints based on whether the inequality is strict or non-strict.

Understanding the Parabola

The sign analysis works because a quadratic function is a parabola. If the leading coefficient (a) is positive, the parabola opens upward and is negative between its roots. If a is negative, the parabola opens downward and is positive between its roots. This determines which intervals satisfy the inequality.

Cases Based on the Discriminant

The discriminant (b² - 4ac) determines how many real roots the quadratic has, which affects the solution of the inequality:

  • If the discriminant is positive, there are two distinct real roots, creating three intervals to test.
  • If the discriminant is zero, there is one repeated root, creating two intervals.
  • If the discriminant is negative, there are no real roots. The quadratic is either always positive or always negative, so the inequality is either always true or always false.

Interval notation is a compact way to write the solution set of an inequality. It uses parentheses and brackets to indicate whether endpoints are included or excluded, and the infinity symbol to represent unbounded intervals.

The union symbol (U) combines multiple intervals. For example, the solution x < -1 or x > 3 is written as (-inf, -1) U (3, inf). This indicates two separate regions on the number line.

Infinity always uses a parenthesis, never a bracket, because infinity is a concept, not a specific number that can be reached or included.

Compound Inequalities

A compound inequality combines two or more simple inequalities into a single statement using the words "and" or "or." These two connectors produce fundamentally different solution sets.

Compound Inequalities with "AND"

An "and" compound inequality requires both conditions to be true simultaneously. The solution is the intersection of the two individual solution sets. The most common form is the double inequality a < x < b, which means x > a AND x < b.

Example: solve -3 < 2x + 1 ≤ 7. Subtract 1 from all three parts: -4 < 2x ≤ 6. Divide all parts by 2: -2 < x ≤ 3. In interval notation: (-2, 3].

Compound Inequalities with "OR"

An "or" compound inequality requires at least one condition to be true. The solution is the union of the two individual solution sets. Example: x + 3 < 1 or 2x - 1 > 5. Solving separately: x < -2 or x > 3. In interval notation: (-inf, -2) U (3, inf).

Absolute Value Inequalities

Absolute value inequalities involve the absolute value function, which returns the distance of a number from zero. Solving these inequalities requires converting them into compound inequalities based on two key rules.

Less-Than Form: |expression| < a

When the absolute value is less than a positive number a, the expression inside must be between -a and a. So |ax + b| < c becomes -c < ax + b < c. This is an "and" compound inequality that produces a bounded interval.

Example: |x - 4| < 3 becomes -3 < x - 4 < 3, which gives 1 < x < 7. In interval notation: (1, 7).

Greater-Than Form: |expression| > a

When the absolute value is greater than a positive number a, the expression inside must be either less than -a or greater than a. So |ax + b| > c becomes ax + b < -c or ax + b > c. This is an "or" compound inequality that produces two unbounded intervals.

Example: |2x + 1| ≥ 5 becomes 2x + 1 ≤ -5 or 2x + 1 ≥ 5, giving x ≤ -3 or x ≥ 2. In interval notation: (-inf, -3] U [2, inf).

Graphing Inequalities on a Number Line

The number line is the standard visual representation for one-variable inequalities. It immediately shows the solution set in a way that interval notation cannot always convey as intuitively.

Conventions

  • An open circle at a point means that point is not included in the solution (strict inequality: < or >).
  • A filled (closed) circle means the point is included (non-strict inequality: ≤ or ≥).
  • A shaded region on the number line shows all the values that satisfy the inequality.
  • An arrow at the end of a shaded region indicates the solution extends to infinity in that direction.

For compound inequalities, the number line makes the distinction between "and" and "or" visually clear. An "and" inequality shows a single connected shaded region. An "or" inequality shows two separate shaded regions with unshaded space between them.

Worked Examples

Example 1: Simple Linear Inequality

Solve: 4x - 7 > 9. Add 7: 4x > 16. Divide by 4: x > 4. Solution: (4, inf). On the number line: open circle at 4, shading to the right.

Example 2: Linear with Negative Coefficient

Solve: -5x + 3 ≤ 18. Subtract 3: -5x ≤ 15. Divide by -5 (flip the sign): x ≥ -3. Solution: [-3, inf). The sign flip is crucial here.

Example 3: Quadratic Inequality

Solve: x² - 5x + 6 < 0. Factor: (x - 2)(x - 3) < 0. Critical points: x = 2 and x = 3. Test intervals: for x = 0, (0-2)(0-3) = 6 > 0. For x = 2.5, (0.5)(-0.5) = -0.25 < 0. For x = 4, (2)(1) = 2 > 0. The expression is negative only between the roots. Solution: (2, 3).

Example 4: Quadratic with No Real Roots

Solve: x² + x + 1 > 0. The discriminant is 1 - 4 = -3 < 0. Since there are no real roots and the leading coefficient is positive, the parabola is always above the x-axis. The expression is always positive, so the inequality is true for all real numbers. Solution: (-inf, inf).

Example 5: Quadratic Less-Than with Two Roots

Solve: 2x² - 8 ≤ 0. Factor: 2(x² - 4) ≤ 0, or 2(x-2)(x+2) ≤ 0. Critical points: x = -2 and x = 2. Since a = 2 > 0, the parabola opens upward, so the expression is non-positive between the roots. Solution: [-2, 2].

Real-World Applications of Inequalities

Business and Finance

Every budget is an inequality. If your monthly income is $4,000 and your fixed expenses are $2,500, the inequality for discretionary spending d is d ≤ 1500. Profit constraints, break-even thresholds, and investment minimum returns are all expressed as inequalities.

Manufacturing constraints are inherently inequality-based. A factory might need to produce at least 500 units to cover fixed costs (x ≥ 500) but cannot exceed 1200 units due to capacity (x ≤ 1200). Together: 500 ≤ x ≤ 1200.

Science and Engineering

Tolerances in engineering are expressed as inequalities. A machine part specified at 2.5cm with a tolerance of 0.01cm must satisfy 2.49 ≤ x ≤ 2.51. Temperature ranges for chemical reactions, pressure limits for vessels, and load capacities for structures are all inequality constraints.

In physics, the speed of light is an upper bound for the velocity of any object with mass: v < c. Heisenberg's uncertainty principle is fundamentally an inequality relating the precision of position and momentum measurements.

Health and Safety

Safe dosage ranges for medications are inequalities. A drug might be effective for doses between 10mg and 50mg: 10 ≤ d ≤ 50. Blood pressure, cholesterol levels, and body temperature all have healthy ranges expressed as inequalities.

Statistics and Data Science

Confidence intervals in statistics are compound inequalities. A 95% confidence interval for a population mean might be expressed as 45.2 ≤ mu ≤ 52.8. Chebyshev's inequality, Markov's inequality, and the Central Limit Theorem all involve inequalities as fundamental mathematical tools.

Optimization

Linear programming, the mathematical technique behind supply chain optimization, scheduling, and resource allocation, is built entirely on systems of linear inequalities. The feasible region is defined by the intersection of all constraint inequalities, and the optimal solution lies on the boundary of that region.

Common Mistakes When Solving Inequalities

  • Forgetting to flip the inequality sign when multiplying or dividing by a negative number. This is the most common error by far.
  • Using brackets with infinity. Infinity is not a number and can never be reached, so always use parentheses: (-inf, 5] not [-inf, 5].
  • Confusing "and" with "or" in compound inequalities. "And" produces an intersection (overlap), "or" produces a union (combination). The solution for "and" is usually smaller.
  • Misinterpreting the sign analysis for quadratic inequalities. The expression is negative between the roots only when the parabola opens upward. Check the sign of the leading coefficient.
  • Applying the absolute value rules incorrectly. Remember: |x| < a gives a bounded interval, while |x| > a gives two unbounded intervals. They are not interchangeable.
  • Dividing by a variable without considering its sign. If you divide both sides of an inequality by a variable, you do not know whether that variable is positive or negative, which means you cannot determine the direction of the inequality.

Frequently Asked Questions

What is an inequality?
An inequality is a mathematical statement comparing two expressions using symbols like < (less than), > (greater than), ≤ (less than or equal to), or ≥ (greater than or equal to). Unlike equations which have specific solutions, inequalities have solution sets representing ranges of values that make the statement true.
How do you solve a linear inequality?
Solve a linear inequality the same way you solve a linear equation: use inverse operations to isolate the variable. The only difference is the critical rule that when you multiply or divide both sides by a negative number, you must reverse (flip) the inequality sign. For example, -3x > 6 becomes x < -2 after dividing by -3.
What is interval notation?
Interval notation is a compact way of writing solution sets. Parentheses ( ) mean the endpoint is excluded (strict inequality), and brackets [ ] mean the endpoint is included (non-strict). For example, x > 3 is (3, inf), x ≤ 5 is (-inf, 5], and 2 < x ≤ 7 is (2, 7]. Infinity always uses parentheses because it is not a reachable number.
Why do you flip the inequality sign when multiplying by a negative?
Multiplying by a negative number reverses the ordering of numbers on the number line. For example, 2 < 5 is true, but after multiplying both by -1, -2 > -5 (not -2 < -5). The order reversed. This reversal happens every time you multiply or divide by a negative value, so the inequality direction must be flipped to keep the statement true.
What is a compound inequality?
A compound inequality combines two simple inequalities using "and" or "or." An "and" compound inequality (like 2 < x < 5) requires both conditions to be true at the same time, producing the intersection of solution sets. An "or" compound inequality (like x < 1 or x > 4) requires at least one condition to be true, producing the union of solution sets.
How do you solve a quadratic inequality?
First, move all terms to one side so you compare to zero. Solve the corresponding equation (set equal to zero) to find the critical points. Plot these on a number line, creating intervals. Test a value from each interval in the original expression to determine the sign. Select intervals where the sign satisfies the inequality, and include endpoints if the inequality is non-strict (≤ or ≥).
What is the difference between < and ≤?
The symbol < means "strictly less than," so the boundary value itself is not included in the solution set. The symbol ≤ means "less than or equal to," so the boundary value is included. On a number line, < is shown with an open (empty) circle at the boundary, while ≤ uses a filled (solid) circle. In interval notation, < uses a parenthesis and ≤ uses a bracket at that endpoint.
Can inequalities have no solution?
Yes. Some inequalities simplify to statements that are always false, like 5 < 3 or x > x + 1. In these cases, no value of x can make the inequality true, and the solution set is empty (denoted as the empty set). A quadratic inequality can also have no solution if the parabola never enters the required region.
What are absolute value inequalities?
Absolute value inequalities involve the absolute value function |x|, which gives the distance from zero. For |expression| < a (where a > 0), the solution is a bounded interval: -a < expression < a. For |expression| > a, the solution is two rays: expression < -a or expression > a. These convert into compound inequalities that you solve using standard methods.
How are inequalities used in real life?
Inequalities model any situation with constraints, limits, or ranges. Budget limits (spending ≤ income), speed limits, temperature ranges for food safety, manufacturing tolerances, safe medication dosages, engineering load limits, and statistical confidence intervals are all expressed as inequalities. Linear programming, which optimizes business decisions, is built entirely on systems of inequalities.
