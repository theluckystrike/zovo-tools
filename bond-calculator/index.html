Bond Pricing Formula

Bond Price = C x [1 - (1+r)^(-n)] / r + F / (1+r)^n C = Annual coupon payment (Face Value x Coupon Rate) r = Yield to maturity (YTM) n = Years to maturity F = Face value (par value) Current Yield = Annual Coupon Payment / Market Price x 100 YTM = Approximate YTM = [C + (F - P)/n] / [(F + P)/2]
